# MPXV-Clade-Ib-sh2023-GISAID-Acknowledgements
We gratefully acknowledge the authors, originating laboratories, and submitting laboratories that generated and shared MPXV Clade Ib/sh2023 genome sequences through GISAID. These data were essential for the genomic analyses presented in our study.

This repository contains the complete GISAID acknowledgement tables associated with the datasets analyzed in the manuscript:

"Genomic insights into the emergence and global spread of Clade Ib/sh2023 Mpox virus"


All data contributors retain ownership of their submitted data in accordance with GISAID's terms and conditions. Users seeking to access the underlying sequence data should do so directly through the GISAID EpiPox database and acknowledge the respective contributors accordingly.
